# 🇰🇼 فطاير ومعجنات الديرة | Kuwaiti Pies & Pastries Online Store

متجر إلكتروني متكامل ومتطور ومخصص لسوق دولة الكويت لبيع الفطائر، المناقيش، المعجنات، البيتزا، وبوكسات الجمعات والديوانية.

![فطاير الديرة الكويت](assets/logo.svg)

---

## 🌟 المميزات الرئيسية (Key Features)

- 🇰🇼 **مخصص لدولة الكويت بالكامل**:
  - التعامل بالدينار الكويتي (**د.ك / KWD**) بدقة 3 منازل عشرية (مثل 1.250 د.ك).
  - قاعدة بيانات متكاملة لكافة محافظات ومناطق الكويت (العاصمة، حولي، الفروانية، الأحمدي، مبارك الكبير، الجهراء).
  - تحديد رسوم التوصيل والوقت التقديري تلقائياً حسب المنطقة.
  - نموذج عنوان كويتي مفصل (القطعة، الشارع، الجادة، المنزل/المبنى، الشقة).

- 🥐 **قائمة طعام غنية ومتنوعة**:
  - فطاير كلاسيكية (جبنة عكاوي، قشقوان، زعتر بلدي بالزيت البكر، لحم بلدي مفروم، سبانخ بالرمان، فلافل، حلوم بالبيستو).
  - مناقيش وصاج (محمرة بالقشقوان، كيري بالعسل، لحم بالجبن).
  - بوكسات الجمعات والديوانيات والمناسبات (بوكس الديرة الملكي 50 حبة، بوكس الترويقة الصباحية 24 حبة، ميني بيتزا وشاورما).
  - بيتزا إيطالية بأطراف محشية وخيارات متعددة.
  - حلويات ساخنة ومشروبات وعصائر وترامس شاي كرك كويتي.

- ⚙️ **تخصيص متقدم للوجبات (Customization)**:
  - اختيار نوع العجين (كلاسيكي، حب بر أسمر، مقرمش، صاج).
  - إضافات مدفوعة ومجانية وملاحظات خاصة للشيف في المطبخ.

- 💳 **طرق دفع متعددة وسريعة**:
  - **بوابة K-NET (كي نت)**: محاكاة تفاعلية مطابقة لشبكة الكويت الوطنية للمدفوعات مع اختيار البنوك الكويتية (الوطني NBK، التمويل KFH، بوبيان، الخليج، برقان، التجاري، وربة، الأهلي).
  - **الطلب المباشر بالواتساب (WhatsApp Checkout)**: إنشاء فاتورة منسقة باللغة العربية وإرسالها بضغطة واحدة إلى واتساب المطعم (+965).
  - **الدفع عند الاستلام (Cash on Delivery)** بالكي نت المتنقل أو نقداً.
  - كوبونات الخصم (`KUWAIT10`, `DEERAH`, `FREE`).

- 🛵 **نظام تتبع مباشر للطلبات (Live Order Tracking)**:
  - صفحة تتبع تفاعلية برقم الطلب توضح مراحل: (تم الاستلام ➔ في الفرن ➔ مع المندوب ➔ تم التسليم).

- 👨‍🍳 **لوحة تحكم إدارة المطبخ والطلبات (Admin Dashboard)**:
  - متابعة الطلبات الواردة لحظياً وتحديث حالتها.
  - إحصائيات المبيعات والأطباق الأكثر طلباً.

- 📱 **تطبيق ويب تقدمي (PWA)**:
  - متجاوب 100% مع الهواتف والأجهزة اللوحية والكمبيوتر وقابل للتثبيت كأيقونة تطبيق على الشاشة الرئيسية.

## 🚀 كيفية التشغيل محلياً (Local Setup)

يمكن فتح المتجر مباشرة دون الحاجة لأي خادم معقد:

1. قم بفتح ملف `index.html` في أي متصفح حديث (Chrome, Safari, Edge, Firefox).
2. أو تشغيل خادم محلي سريع عبر Python أو أي خادم ويب:
```bash
python3 -m http.server 8000
```
ثم فتح المتصفح على: `http://localhost:8000`

---

## 🌐 النشر على GitHub Pages

المشروع يحتوي بالفعل على ملف GitHub Actions Workflow (`.github/workflows/deploy.yml`).
بمجرد رفع الملفات على الفرع الرئيسي (`main` أو `master`):
1. انتقل إلى إعدادات المستودع على GitHub: **Settings -> Pages**.
2. في قسم **Source**، اختر **GitHub Actions**.
3. سيتم نشر الموقع تلقائياً على رابط GitHub Pages الخاص بك.
